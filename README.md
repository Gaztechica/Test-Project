# Автоматизация тестирования (API & UI)

Проект представляет собой комплексный фреймворк для автоматизации тестирования API аутентификации и пользовательского интерфейса (UI). Построен на базе Java, Cucumber (BDD) и JUnit 5, с интеграцией Allure-отчетности и контейнеризацией через Docker.

## Ссылка на файлы документации
* [Архитектурный обзор проекта](solution-overview.md)
* [Руководство по передаче проекта и ограничения (Handoff)](handoff.md)

## Структура проекта
* `src/test/java/example/` — исходный код автотестов (клиенты, шаги, конфигурация, тесты).
* `src/test/resources/` — конфигурационные файлы, тестовые данные (`response-token.json`, SQL-скрипты) и BDD-сценарии (`.feature`).
* `docker-compose.yml` — конфигурация для развертывания инфраструктуры тестирования (БД, окружение).
* `Jenkinsfile` — описание CI/CD пайплайна сборки и запуска тестов.

## 🚀 Как запустить тесты:

1. запустить тесты через терминал с помощью стандартных команд Maven:

```bash
# Очистить прошлые сборки и запустить все тесты
mvn clean test
```
2. запустить это локально на компьютере через Docker
```bash
# Сборка Docker-образа (Image)
docker build -t my-api-tests .
```
```bash
# Запуск контейнера из собранного образа
docker run --rm my-api-tests
```

## Быстрый запуск
Для запуска всех тестов локально выполните скрипт автоматизации:
```bash
./run_tests.sh
```
