# Документация по передаче проекта (Handoff)

## Известные ограничения системы

1. **Зависимость UI-тестов от Docker**
   * Все тесты пользовательского интерфейса и тесты, проверяющие интеграцию с базой данных, требуют предварительно поднятого локального или удаленного окружения Docker (`docker-compose.yml`). Без работающего контейнера PostgreSQL тесты инициализации завершатся с ошибкой соединения.
2. **Нестабильные (Flaky) тесты**
   * Тест проверки таймаута сессии при аутентификации временно помечен аннотацией `@Disabled` из-за нестабильного поведения сетевого контура на стороне тестового стенда Heroku (`restful-booker.herokuapp.com`).
3. **Параллельный запуск**
   * Текущая версия фреймворка поддерживает потокобезопасный параллельный запуск только на уровне API-тестов. Одновременный запуск UI-тестов в несколько потоков требует настройки удаленного Selenium Grid / Selenoid.

## Инструкции по локальному запуску

### Предварительные требования
* **Java:** Версия 17 или выше.
* **Maven:** Установлен и добавлен в PATH.
* **Docker & Docker Compose:** Запущены в системе.

### Пошаговый запуск

1. **Клонирование репозитория:**
   ```
   https://github.com/Gaztechica/Test-Project.git
   ```
2. **Развертывание инфраструктуры (БД):**
   ```bash
   docker-compose up -d
   ```
3. **Запуск тестового набора через Maven:**
   ```bash
   mvn clean test
   ```
4. **Генерация и открытие отчета Allure:**
   ```bash
   allure serve target/allure-results
   ```
